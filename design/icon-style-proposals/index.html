Themakoppeling

Geen vaste kleur in de paden.

.toolbar-icon {
  color: var(--theme-text);
  --icon-accent: var(--theme-accent);
  --icon-tint: var(--theme-accent-soft);
}
/* SVG gebruikt currentColor + deze twee tokens.
   Bij extern IMG-gebruik kleuren apart meegeven. */

SVG’s werken direct in webinterfaces. Dezelfde geometrie kan later naar de Rust-renderer. De proeven zijn nog niet in de gedeelde crate opgenomen.

Stijl B is gekozen. De accentgeometrie is herzien; A en C blijven eerdere stijlproeven. Vorm- en kleurreferentie: OpenAEC-website. De website en de thema’s van Claude zijn niet aangepast.
