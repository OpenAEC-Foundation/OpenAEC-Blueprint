# OpenAEC UI-harmonisatie

Deze repository bevat een volledig in Rust getekende desktop-Style Repo en de afzonderlijk te verpakken [`openaec-ui`-crate](crates/openaec-ui/). De native interface gebruikt `iced` en volgt de regio's, maten, thema's en typografie van de OpenAEC Tauri-template: titelbalk, optionele ribbon of werkstroomnavigatie, documenttabs, werkgebied, status en instellingen. Er is geen React, JavaScript, WebView of Tauri-runtime nodig.

Het [uitgebreide UI-onderzoek van 22/23 oktober 2026](design/ui-onderzoek-2026-10-22/README.md) bundelt typografie/vorm, vijftien UI-onderwerpen, bronnen, begrensde uitgevoerde proeven en zes voorgestelde volledige taakproeven. Begin bij het [ochtendadvies](design/ui-onderzoek-2026-10-22/outputs/OpenAEC-UI-ochtendoverzicht.html). Het onderzoek is overlegmateriaal; bestaande ontwerpbesluiten en productiecomponenten blijven ongewijzigd.

De [schermlezerproef van 23 oktober 2026](design/schermlezerproef/README.md) toetst bevinding UI-001 op Windows: iced 0.14, waarop `openaec-ui` sinds die dag draait, en de COSMIC-fork geven een schermlezer nog niets door; plushie-iced geeft rollen, namen en acties, maar meldt geen focus en kan geen tekst invullen. De map bevat het proefscherm, de meetscripts en de uitslagen.

Start de Style Repo met:

```bash
cargo run --bin style_repo
```

De 2.854 bronrecords zijn **geen telling van unieke iconen**. Zoek op functie of app, vergelijk vormen op licht/donker en 16/24/32 px, of open de app×functie-matrix. Broncommit, concrete aanroep, bestaande beoordelingen en geometriehash blijven per record beschikbaar. De pagina werkt zelfstandig vanaf schijf; [JSON](harmonization/function-icon-catalog.json) en [CSV](harmonization/function-icon-catalog.csv) bewaren de volledige inventaris.

Dit is de broninventaris voor de nieuwe iconenset, met expliciete voorlopige functieclusters. Gelijke geometrie bewijst geen gelijke opdracht; andere XML-geometrie kan visueel alsnog overeenkomen. Onbeoordeelde bronplaatsen, teksticonen en geparameteriseerde vormen blijven herkenbaar. FEM heeft nog geen toegankelijke bron. Runtime-extensies en de semantische beoordeling zijn niet volledig afgedekt; de bestaande Rust-iconen zijn niet gewijzigd. De uitsluitingen voor technische tekeningen, plaatsbare symbolen, ongebruikte catalogusvormen en illustraties staan in de JSON. Zie **Dekking en open werk** in het overzicht.

Gericht vernieuwen en controleren: `python scripts/collect_app_icon_sources.py`, daarna `python scripts/build_function_icon_catalog.py` en `python scripts/check_function_icon_catalog.py`. ## Tokens 0.4 voor Rust en web

## Via GitHub Desktop pushen

1. Kies **File → Add local repository** en selecteer `/home/aia04/Documenten/GitHub/OpenAEC-app-kopie`.
2. Meld je in GitHub Desktop aan met een account dat toegang heeft tot de private [OpenAEC-Style-Repo](https://github.com/OpenAEC-Foundation/OpenAEC-Style-Repo).
3. Commit je wijzigingen en gebruik **Push origin**. De lokale `main` volgt al `origin/main`.

De remote staat voorlopig op privé. Pointcloud gebruikt een gelijkgehouden lokale crate-kopie zodat een publieke checkout zonder toegang tot deze private repository kan bouwen. `python3 scripts/check_portable_ui.py` controleert de inhoudelijke gelijkheid. De bestaande repository `OpenAEC-style-book` is niet gewijzigd.

De lokale map `harmonization/sources/` en Rust-buildmap `target/` staan in `.gitignore`, zodat ze niet per ongeluk meegepusht worden. Controleer licenties van bronassets vóór definitief gebruik in een gedeelde crate.
